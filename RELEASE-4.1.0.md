# Release 4.1.0

Linux Hotspot Manager 4.1.0 makes the administration GUI comprehensive: every current service method is exposed through dedicated controls, and integration-dependent MyPublicWiFi/MyHotspot-style functions have configuration panels.

The feature target is based on the public feature descriptions of MyPublicWiFi and MyHotspot, including hotspot modes, authentication, vouchers, firewall/service filtering, URL logging, bandwidth management, adblock, port forwarding, billing, SMS and staff/statistics concepts. See the upstream feature references in the project research notes.

This release does not fake third-party payment/SMS services or claim driver-specific repeater support without host testing.
